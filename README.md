# Fauna Randomizer

**Fauna Randomizer** — приложение для случайного выбора победителей из списка участников (например, email-адресов). Проект написан на игровом движке **Godot Engine 4.5** и распространяется в виде исходного кода.

## 🎯 Возможности

- Ввод списка участников (каждый с новой строки)
- Указание количества победителей
- Анимация вращения колеса с плавной остановкой на случайном участнике
- Звуковое сопровождение: фоновая музыка, звуки вращения, победы, нажатий и наведения на кнопки
- Пост-обработка изображения: пикселизация, постеризация, дизеринг, хроматическая аберрация, виньетка
- Анимированные кнопки, контейнеры и модальные окна
- Поддержка русского языка в интерфейсе

## 🛠 Технологии

- **Godot Engine 4.5** (Forward Plus)
- **GDScript** — язык написания логики
- **Шейдеры** (написаны на Godot Shading Language)
- **Аудио** в формате OGG

## 🚀 Установка и запуск

1. Скачайте и установите [Godot Engine 4.5](https://godotengine.org/download) (стандартная версия).
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/fauna-randomizer.git
   ```
3. Откройте Godot и импортируйте проект, указав путь к папке с проектом.
4. Запустите главную сцену (`Main.tscn`) или нажмите **F5** для запуска проекта.

### Экспорт

Для сборки исполняемого файла под нужную платформу:
1. Установите экспортные шаблоны через **Editor → Manage Export Templates**.
2. Настройте пресет экспорта в **Project → Export**.
3. Нажмите **Export Project**.

## 📖 Использование

1. В правой части экрана введите список участников в текстовое поле (каждый email или имя — с новой строки).
2. Укажите желаемое количество победителей в поле ниже.
3. Нажмите кнопку **«Запуск»**.
4. Колесо начнёт вращаться и остановится на случайном участнике. Появится модальное окно с именем победителя.
5. Процесс повторяется, пока не будет выбрано указанное количество победителей.
6. После завершения отобразится список всех победителей и кнопка **«Сбросить»** для возврата к вводу.

## ⚙️ Особенности реализации

- **Анимация колеса**: используется `Tween` с замедлением `TRANS_QUART` и `EASE_OUT`. Позиция списка участников анимируется, создаётся эффект вращения.
- **Звуковые тики**: при пересечении границы элемента воспроизводится звук с ограничением по минимальному интервалу и максимальной полифонии.
- **Пост-обработка**: шейдер `post_process.gdshader` накладывается на весь экран через `ColorRect` в `CanvasLayer`.
- **Адаптивность**: интерфейс масштабируется под разрешение 1920×1080 с режимом растяжения `viewport` и аспектом `expand`.
